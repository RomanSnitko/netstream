# Agent - Сборщик системных логов

## Зона ответственности
Агент запускается на каждой Linux машине и собирает системные события из различных источников 
(syslog, journald, dmesg). Приводит события к единому формату, батчит их и отправляет на 
центральный Gateway по TCP.

## Что делает
1. **Читает системные логи** - мониторит `/var/log/syslog` (или journald через systemd API)
2. **Нормализует события** - преобразует в структуру `Event` с полями: agent_id, timestamp, 
source, raw_message, severity
3. **Батчит события** - накапливает до 100 событий или 1 секунды
4. **Сериализует в JSON** - конвертирует батч в формат `{"events": [...]}`
5. **Отправляет по TCP** - подключается к Gateway и отправляет JSON

## Архитектура
- **Agent** - основной класс, управляет потоками и батчингом
- **TcpSender** - TCP клиент с автореконнектом
- **Потоки**:
  - `read_syslog()` - читает логи и добавляет в батч
  - `batch_timer_loop()` - таймер отправки каждую секунду

## Триггеры отправки
- Батч достиг 100 событий → немедленная отправка
- Прошла 1 секунда → отправка накопленных событий
- Shutdown → отправка оставшихся событий
