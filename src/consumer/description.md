# Consumer - Воркер для агрегации и сохранения

## Зона ответственности
Consumer читает события из Kafka, считает агрегаты и сохраняет данные в PostgreSQL.
Обеспечивает персистентность и аналитику.

## Что делает
1. **Читает из Kafka** - подписывается на топики `netstream.events` и `netstream.alerts`
2. **Агрегирует данные** - считает статистику по источникам, категориям, временным интервалам
3. **Batch insert в PostgreSQL** - накапливает события и вставляет пачками для производительности
4. **Сохраняет**:
   - Все события в таблицу `events`
   - Алерты в таблицу `alerts`
   - Агрегаты в таблицу `event_stats` (по часам/дням)
   - Информацию об агентах в `agents`

## Архитектура
- **Consumer** - основной класс, координирует обработку
- **KafkaConsumer** - читает сообщения из Kafka
- **PostgresWriter** - batch insert в БД

## Агрегаты (примеры)
- Количество событий по источникам за час
- Количество алертов по типам за день
- Топ агентов по количеству событий
- Распределение по severity levels

## Обработка
```
Kafka → Deserialize → Aggregate → Batch → PostgreSQL
```

## Оптимизации
- Batch insert (100-1000 событий за раз)
- Prepared statements
- Connection pooling
- Периодический flush (каждые 5 секунд)
